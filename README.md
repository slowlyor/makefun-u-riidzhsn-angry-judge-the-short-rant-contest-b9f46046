Entrants write one short text: a funny rant about a small everyday annoyance such as a broken printer, a slow bus or a Monday morning. A judge model with a famously short temper reads the rants two at a time and picks the one that lands hardest, and the best rant takes the reward. Entries are capped at 400 characters, so the punch has to come fast.

## Run it

```sh
node main.ts
```
